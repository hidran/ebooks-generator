# Parte VI. Photogallery

El proyecto principal del libro: una aplicación full-stack con una API en Laravel, un panel de administración con Filament, un frontend en React, subida de fotos procesadas en cola y el deploy final en AWS. El código está en el repositorio público `github.com/hidran/claude-code-book-photogallery`, con una rama para cada etapa.

El método es Spec Driven Development. Primero eliges el stack con motivos de verdad y escribes las especificaciones (capítulo 17). Luego las conviertes en los tres archivos que guían el trabajo: requisitos, diseño y un plan de 124 tareas en 14 fases (capítulo 18). Después ejecutas por oleadas, con una revisión al final de cada wave (capítulo 19), también en paralelo sobre worktrees separados (capítulo 20). A mitad de camino llegan funcionalidades no previstas, como pasa siempre (capítulo 21). Antes de pasar a producción haces QA, la revisión integrada y una segunda opinión de otro modelo (capítulo 22). Por último, el deploy con CloudFormation (capítulo 23).

Son los capítulos más largos del libro. Conviene leerlos con el repositorio abierto al lado.

# Parte IV. Control y automatización

Esta parte es nueva en la segunda edición. En la primera los proyectos funcionaban, pero el control sobre lo que Claude podía hacer dependía sobre todo de las instrucciones de CLAUDE.md y de tu atención. Hoy Claude Code arranca en auto mode y trabaja largos ratos sin preguntarte nada, así que conviene saber exactamente dónde están los límites y cómo moverlos.

Cinco capítulos, todos sobre el mismo pequeño proyecto de laboratorio, `cc-advanced-lab`: un script de Python, un CSV y un archivo `.env` que no hay que tocar. El capítulo 11 trata los modos de permisos, las reglas allow, ask y deny y el sandbox. El 12, los hooks, que convierten un "acuérdate de" en una regla que salta siempre. El 13, MCP, para conectar Claude con GitHub, con una base de datos y con los demás servicios que usas. El 14, los plugins, para empaquetarlo todo y pasárselo al equipo. El 15, el contexto y la memoria, es decir, cómo mantener bajo control lo que Claude ve y recuerda.

Puedes leerla también después de los proyectos de las partes V y VI. Si trabajas con código que importa, léela antes.

# Parte I. Fundamentos

Tres capítulos para empezar con buen pie. El primero instala Claude Code y te lleva por una primera vuelta: comandos, cuentas, modos, un primer prompt sobre un proyecto de verdad. El segundo abre el capó: qué pasa entre el momento en que pulsas Intro y el momento en que un archivo cambia en el disco, por qué el modelo nunca ejecuta nada por su cuenta y qué te protege cuando el agente se equivoca. El tercero va de prompts, es decir, de darle a ese ciclo un objetivo claro y una forma de comprobarlo, con Plan Mode como costumbre desde el primer día.

Si ya usas Claude Code a diario, puedes hojear el capítulo 1. El capítulo 2 léelo de todas formas: casi todo lo que viene después, de las skills a los hooks, tiene un lugar preciso en el esquema que construye.

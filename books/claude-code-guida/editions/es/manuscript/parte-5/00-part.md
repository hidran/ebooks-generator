# Parte V. Landing page

El primer proyecto completo: una landing page para un producto real, desde el "quiero una landing" hasta el enlace público en Firebase. Es pequeño a propósito. Te permite probar el ciclo entero en una tarde: mockup, plan de tareas atómicas, ejecución tarea a tarea con commits, revisión y deploy.

Los mismos pasos, a mayor escala, son los que usarás con la Photogallery en la parte VI. Si aquí algo no te cuadra, es el momento de descubrirlo.

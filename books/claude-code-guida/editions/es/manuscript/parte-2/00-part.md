# Parte II. Análisis de datos

El primer caso de uso serio de este libro es un archivo CSV, no una aplicación web. Los datos son un banco de pruebas honesto: o los números cuadran o no cuadran, y lo ves enseguida. En estos tres capítulos partes de una exportación de ventas, haces que Claude la lea, planificas el análisis con Plan Mode y luego conviertes las conversaciones en scripts: un informe de Excel con fórmulas de verdad, gráficos con matplotlib, un pequeño dashboard con Flask y un PDF generado con ReportLab.

No hace falta ser analista de datos. Hace falta un poco de Python y la costumbre de comprobar los resultados en lugar de fiarte.

# Parte III. Ampliar Claude Code

Tras unas semanas con Claude Code te das cuenta de que repites siempre lo mismo: las convenciones del proyecto, los comandos para ejecutar los tests, el prompt para una revisión, el de un mensaje de commit decente. Esta parte sirve para dejar de repetirlo.

Se empieza por CLAUDE.md, el archivo que Claude lee al comienzo de cada sesión. Luego los comandos personalizados, prompts guardados que invocas con una barra, y el plugin Superpowers. Después las skills, que hacen lo mismo con más estructura y que Claude puede usar también por su cuenta cuando encajan. Por último los agentes: instancias separadas con su propio contexto, sus tools y su modelo, para cuando una tarea merece una cabeza aparte.

El último capítulo cierra con una pregunta que te harás a menudo: ¿para esto necesito un comando, una skill o un agente?

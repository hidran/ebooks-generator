# Part II. Data analysis

The first serious use case in this book is a CSV file, not a web app. Data is an honest test bench: the numbers either add up or they don't, and you find out right away. Across these three chapters you start from a sales export, have Claude read it, plan the analysis with Plan Mode, then turn the conversations into scripts: an Excel report with real formulas, matplotlib charts, a small Flask dashboard and a PDF generated with ReportLab.

You don't need to be a data analyst. You need a bit of Python and the habit of checking results instead of trusting them.

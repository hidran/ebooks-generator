# Part VI. Photogallery

The main project of the book: a full-stack application with a Laravel API, a Filament admin panel, a React frontend, photo uploads processed in a queue, and a final deploy on AWS. The code is in the public repository `github.com/hidran/claude-code-book-photogallery`, with a branch for each milestone.

The method is Spec Driven Development. First you pick the stack for real reasons and write the specs (chapter 17). Then you turn them into the three files that drive the work: requirements, design and a plan of 124 tasks in 14 phases (chapter 18). Then you execute in waves, with a review after each wave (chapter 19), in parallel on separate worktrees too (chapter 20). Halfway through, unplanned features show up, as they always do (chapter 21). Before going to production you run QA, the built-in review and a second opinion from another model (chapter 22). Finally, the deploy with CloudFormation (chapter 23).

These are the longest chapters in the book. Read them with the repository open next to you.

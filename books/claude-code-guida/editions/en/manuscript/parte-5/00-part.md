# Part V. Landing page

The first complete project: a landing page for a real product, from "I want a landing page" to a public link on Firebase. It's small on purpose. It lets you try the whole cycle in an afternoon: mockup, plan of atomic tasks, task-by-task execution with commits, review, deploy.

The same steps, scaled up, are the ones you'll use on the Photogallery in Part VI. If something doesn't click here, this is the right time to find out.

# Part III. Extending Claude Code

After a few weeks with Claude Code you notice you keep typing the same things: the project conventions, the commands that run the tests, the prompt for a review, the one for a decent commit message. This part is about not typing them again.

It starts with CLAUDE.md, the file Claude reads at the start of every session. Then custom commands, which are saved prompts you call with a slash, and the Superpowers plugin. Then skills, which do the same with more structure and which Claude can also pick up on its own when they fit. Finally agents: separate instances with their own context, tools and model, for when a job deserves a head of its own.

The last chapter ends with a question you'll ask yourself often: does this need a command, a skill or an agent?

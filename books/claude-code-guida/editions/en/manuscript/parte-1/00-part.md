# Part I. Foundations

Three chapters to get off on the right foot. The first installs Claude Code and takes you through a first round: commands, accounts, modes, a first prompt on a real project. The second opens the hood: what happens between the moment you press Enter and the moment a file changes on disk, why the model never runs anything by itself, and what protects you when the agent gets it wrong. The third is about prompting, which means giving that loop a clear goal and a way to check it, with Plan Mode as a habit to pick up from day one.

If you already use Claude Code every day you can skim chapter 1. Read chapter 2 anyway: almost everything that follows, from skills to hooks, has a precise place in the picture it draws.

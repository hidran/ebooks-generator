# Parte III. Estendere Claude Code

Dopo qualche settimana con Claude Code ti accorgi che ripeti sempre le stesse cose: le convenzioni del progetto, i comandi per lanciare i test, il prompt per fare una review, quello per scrivere un commit decente. Questa parte serve a smettere di ripeterle.

Si parte da CLAUDE.md, il file che Claude legge a ogni sessione. Poi i custom command, cioè prompt salvati che richiami con una barra, e il plugin Superpowers. Poi le skill, che fanno la stessa cosa con più struttura e che Claude può usare anche da solo quando servono. Infine gli agent: istanze separate con il loro contesto, i loro tool e il loro modello, da usare quando un compito merita una testa a parte.

L'ultimo capitolo chiude con una domanda che ti farai spesso: per questa cosa mi serve un command, una skill o un agent?

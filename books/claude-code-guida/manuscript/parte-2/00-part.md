# Parte II. Analisi dati

Il primo caso d'uso serio di questo libro è un file CSV, non un'applicazione web. I dati sono un banco di prova onesto: o i numeri tornano o non tornano, e te ne accorgi subito. In questi tre capitoli parti da un export di vendite, lo fai leggere a Claude, pianifichi l'analisi con Plan Mode, poi trasformi le conversazioni in script: un report Excel con formule vere, grafici matplotlib, una piccola dashboard Flask e un PDF generato con ReportLab.

Non serve essere data analyst. Serve un po' di Python e la voglia di controllare i risultati invece di fidarti.

# Parte VI. Photogallery

Il progetto principale del libro: un'applicazione full-stack con API Laravel, pannello admin Filament, frontend React, upload di foto con elaborazione in coda, e il deploy finale su AWS. Il codice è nel repository pubblico `github.com/hidran/claude-code-book-photogallery`, con un branch per ogni tappa.

Il metodo è lo Spec Driven Development. Prima scegli lo stack con motivazioni vere e scrivi le specifiche (capitolo 17). Poi le trasformi nei tre file che guidano il lavoro: requisiti, design e un piano di 124 task in 14 fasi (capitolo 18). Poi esegui a ondate, con review dopo ogni wave (capitolo 19), anche in parallelo su worktree separati (capitolo 20). A metà strada arrivano feature non previste, come succede sempre (capitolo 21). Prima di andare in produzione fai QA, review integrata e un secondo parere da un altro modello (capitolo 22). Infine il deploy con CloudFormation (capitolo 23).

Sono i capitoli più lunghi del libro. Conviene leggerli con il repository aperto accanto.

# Glossary (claude-code-guida)

Terms to keep consistent across the IT, EN and ES editions. STYLE.md section 5 explains
the register; this table fixes the words.

## Invariant: never translated

Product, command and vendor names appear identically in every edition, in prose too:
Claude Code, Claude, Anthropic, Claude Opus, Claude Sonnet, Claude Haiku, Plan Mode,
auto mode, CLAUDE.md, CLAUDE.local.md, AGENTS.md, REVIEW.md, MEMORY.md, SKILL.md,
MCP (Model Context Protocol), Superpowers, Photogallery, Spec Driven Development (SDD),
vibecoding, ultrareview, agent view, Laravel, Filament, Sanctum, React, Vite,
Tailwind CSS, Firebase, AWS, CloudFormation, ECS Fargate, RDS, S3, CloudFront, ALB,
GitHub, Git, VS Code, WSL 2, Python, pandas, openpyxl, matplotlib, Flask, Chart.js,
ReportLab, Gemini, Codex, Kimi.

Every slash command (`/compact`, `/goal`), CLI flag, file path, setting key, tool name
(`Read`, `Edit`, `Bash`, `Agent`) and environment variable is copied verbatim.

# Parte I — Iniziare con PHP {.unnumbered}

Prima di scrivere una sola riga di codice serve un ambiente di lavoro solido. In questa prima parte scopriamo che cos'è PHP e perché, a distanza di trent'anni dalla nascita, muove ancora gran parte del web; poi installiamo PHP, MySQL e un web server su Windows, macOS e Linux, e configuriamo Visual Studio Code per lavorare con PHP in modo produttivo.

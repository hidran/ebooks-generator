# Conclusions {.unnumbered}

Here we are at the end of this journey — even if I don't like calling it the end, because PHP is a language that continually evolves and with it the way of working of those who use it every day also evolves.

With this book I wanted to summarize the knowledge I have built while developing with PHP since 2001: the most important things, the things I find every day in my work, passed chapter by chapter. I am particularly happy with the projects we built together: the user management system, with a dynamic website complete with authentication and image upload, and the enterprise MVC blog, with Composer, repositories, services, PSR-7/15, tests, Docker and CI/CD. They are proof that with modern PHP you can build solid, tidy and production-ready applications.

There are always topics to explore — PHP security and web security alone deserve ongoing study. Don't stop here: continue studying, not only PHP but also other web languages ​​and technologies, and consolidate HTML and CSS well. You have to study every day to keep up to date: that's how I do it, and I always will.

If you already work in the web world, I hope this book makes you more productive. If you don't have a job yet, the possibilities in the PHP world are enormous: the language still moves most of the web, and those who know it well are always in demand.

Thanks for coming this far. See you in the next book.

*Hidran Arias*

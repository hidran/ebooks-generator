# Parte VII: PHP orientado a objetos {.unnumbered}

La programación orientada a objetos es el corazón del PHP profesional. Comenzamos desde clases, propiedades y métodos, para llegar a la herencia, interfaces, traits, propiedades escritas, promoción de propiedades del constructor, solo lectura, enumeración, método mágico y las características modernas del lenguaje.

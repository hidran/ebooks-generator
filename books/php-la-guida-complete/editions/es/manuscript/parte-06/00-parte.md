# Parte VI — Proyecto: Sistema de gestión de usuarios {.unnumbered}

Es hora de juntarlo todo. En esta parte construimos una aplicación completa de gestión de usuarios desde cero: diseño con Bootstrap, lista con clasificación, paginación y búsqueda, CRUD completo, carga de imágenes con miniaturas, autenticación con inicio de sesión, registro, recordarme, protección CSRF y gestión de roles.

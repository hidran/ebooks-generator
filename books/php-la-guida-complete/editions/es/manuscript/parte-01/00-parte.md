# Parte I: Primeros pasos con PHP {.unnumbered}

Antes de escribir una sola línea de código, necesita un entorno de trabajo sólido. En esta primera parte descubrimos qué es PHP y por qué, treinta años después de su nacimiento, todavía mueve gran parte de la web; luego instalamos PHP, MySQL y un servidor web en Windows, macOS y Linux, y configuramos Visual Studio Code para trabajar con PHP de manera productiva.

# Glossario (php-la-guida-complete)

Termini da mantenere coerenti in tutto il libro (edizione italiana) e nelle traduzioni.

## Convenzioni per l'edizione italiana

Termini tecnici che restano in **inglese** (invariati, con genere indicato):

| Termine | Genere/uso in italiano |
|---|---|
| array | un array, gli array (invariabile) |
| framework | il framework |
| browser | il browser |
| server / web server | il server, il web server |
| database | il database |
| query | la query, le query |
| form | il form, i form |
| upload / download | l'upload, il download |
| login / logout | il login, il logout |
| cookie | il cookie, i cookie |
| token | il token |
| deploy | il deploy |
| debug / debugger / debugging | il debug, il debugger |
| namespace | il namespace |
| trait | il trait, i trait |
| router / route (nel codice) | il router; la rotta (concetto) |
| controller / model / view (MVC) | il controller, il model, la view |
| autoload / autoloading | l'autoload |
| hash | l'hash |
| backend / frontend | il backend, il frontend |
| endpoint | l'endpoint |
| bug | il bug |
| loop (solo se citato) | preferire "ciclo" |

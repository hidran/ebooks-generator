# Lezione 92b. Test che mentono: copertura e mutation testing

## Punti chiave

### Mutation testing

- Mutante: il codice con un piccolo errore voluto
- Per esempio: &gt;= diventa &gt;, condizione negata, return 0
- Un test fallisce: mutante ucciso
- Tutti i test passano: mutante sopravvissuto
- Mutation score: mutanti uccisi su mutanti generati

### Test che mentono nel nostro corso

- 12b: solo stringhe letterali, una soluzione con == passava
- 13b: il return 0 provvisorio passava già il test dei contanti
- 37b, prima versione: con &gt;= 3001 al posto di 3000 i test restavano verdi
- Correzioni: new String, valore provvisorio -1, test sul confine

### Quando usarlo (KISS)

- Sul cuore del dominio: prezzi, sconti, soglie, permessi
- È lento: ogni mutante riesegue i test che lo coprono
- targetClasses e targetTests limitano il lavoro
- Fuori da verify: a richiesta o in un build automatico separato, di notte
- Nessuna soglia al 100%: esistono mutanti equivalenti

## Codice della lezione

`src/main/java/com/shop/order/ShippingPolicy.java`

~~~java
package com.shop.order;

public class ShippingPolicy {
    private static final int FREE_FROM = 5000;
    private static final int REDUCED_FROM = 3000;
    private static final int REDUCED_FEE = 200;
    private static final int STANDARD_FEE = 500;

    public int feeInCents(int totalInCents) {
        if (totalInCents < 0) {
            throw new IllegalArgumentException("Total must not be negative");
        }
        if (totalInCents >= FREE_FROM) {
            return 0;
        }
        if (totalInCents >= REDUCED_FROM) {
            return REDUCED_FEE;
        }
        return STANDARD_FEE;
    }
}
~~~

`src/test/java/com/shop/order/ShippingPolicyTests.java`

~~~java
package com.shop.order;

import org.junit.jupiter.api.Test;
import static org.assertj.core.api.Assertions.assertThat;
import static org.assertj.core.api.Assertions.assertThatThrownBy;

class ShippingPolicyTests {
    private final ShippingPolicy policy = new ShippingPolicy();

    @Test
    void largeOrder() {
        assertThat(policy.feeInCents(8000)).isEqualTo(0);
    }

    @Test
    void mediumOrder() {
        assertThat(policy.feeInCents(4000)).isEqualTo(200);
    }

    @Test
    void smallOrder() {
        assertThat(policy.feeInCents(1000)).isEqualTo(500);
    }

    @Test
    void negativeTotal() {
        assertThatThrownBy(() -> policy.feeInCents(-1));
    }

    @Test
    void boundariesFromBothSides() {
        assertThat(policy.feeInCents(5000)).isEqualTo(0);
        assertThat(policy.feeInCents(4999)).isEqualTo(200);
        assertThat(policy.feeInCents(3000)).isEqualTo(200);
        assertThat(policy.feeInCents(2999)).isEqualTo(500);
        assertThat(policy.feeInCents(0)).isEqualTo(500);
    }
}
~~~

- Asserzioni esatte e confini da tutte e due le parti

- Mutation testing dove conta: il dominio

# Lezione 110. Immagine nativa con GraalVM (facoltativa)

## Punti chiave

### La JVM e l'immagine nativa

- JVM: classi caricate all'avvio, il JIT ottimizza a runtime
- Immagine nativa: tutto il programma analizzato nella build
- Mondo chiuso: entra solo il codice raggiungibile dal main
- Riflessione e risorse lette a runtime vanno dichiarate

> Percorso: sorgenti, poi javac, poi AOT di Spring, poi native-image, poi eseguibile.

### Costi e benefici

- Avvio in decine di millisecondi invece di secondi
- Meno memoria: niente JIT e niente classi caricate a runtime
- Build lunga, in minuti, e una macchina capiente
- Hint per riflessione, risorse e proxy; meno flessibilità
- Prestazioni di picco spesso più basse senza ottimizzazioni guidate

### Quando conviene

- Funzioni serverless e job brevi che partono spesso
- Molte istanze piccole, dove conta la memoria
- Non serve per un servizio che resta acceso per giorni
- KISS: prima misuriamo, poi decidiamo; la JVM resta la scelta predefinita

~~~java
package com.shop.catalog;

import java.io.IOException;
import org.springframework.boot.ApplicationArguments;
import org.springframework.boot.ApplicationRunner;
import org.springframework.context.annotation.ImportRuntimeHints;
import org.springframework.core.io.ClassPathResource;
import org.springframework.stereotype.Component;
import static java.nio.charset.StandardCharsets.UTF_8;

@Component
@ImportRuntimeHints(CatalogRuntimeHints.class)
public class DemoCatalogLoader implements ApplicationRunner {
    static final String RESOURCE = "catalog/demo-products.csv";
    private final ProductRepository repository;

    public DemoCatalogLoader(ProductRepository repository) {
        this.repository = repository;
    }

    @Override
    public void run(ApplicationArguments args) throws IOException {
        String csv = new ClassPathResource(RESOURCE).getContentAsString(UTF_8);
        for (String line : csv.lines().toList()) {
            String[] fields = line.split(",");
            repository.save(new Product(0, fields[0], Integer.parseInt(fields[1])));
        }
    }
}
~~~

`src/main/java/com/shop/catalog/CatalogRuntimeHints.java`

~~~java
package com.shop.catalog;

import org.springframework.aot.hint.RuntimeHints;
import org.springframework.aot.hint.RuntimeHintsRegistrar;

public class CatalogRuntimeHints implements RuntimeHintsRegistrar {
    @Override
    public void registerHints(RuntimeHints hints, ClassLoader classLoader) {
        hints.resources().registerPattern(DemoCatalogLoader.RESOURCE);
    }
}
~~~

`src/main/java/com/shop/catalog/InMemoryProductRepository.java`

~~~java
package com.shop.catalog;

import java.util.Comparator;
import java.util.List;
import java.util.Optional;
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.atomic.AtomicLong;
import org.springframework.stereotype.Repository;

@Repository
public class InMemoryProductRepository implements ProductRepository {
    private final ConcurrentHashMap<Long, Product> products = new ConcurrentHashMap<>();
    private final AtomicLong sequence = new AtomicLong();

    @Override
    public List<Product> findAll() {
        return products.values().stream().sorted(Comparator.comparingLong(Product::id)).toList();
    }

    @Override
    public Optional<Product> findById(long id) {
        return Optional.ofNullable(products.get(id));
    }

    @Override
    public Product save(Product product) {
        long id = product.id() == 0 ? sequence.incrementAndGet() : product.id();
        Product stored = new Product(id, product.name(), product.priceInCents());
        products.put(id, stored);
        return stored;
    }

    @Override
    public boolean deleteById(long id) {
        return products.remove(id) != null;
    }
}
~~~


## Riepilogo

- Profilo native: process-aot genera codice Java al posto della riflessione
- RuntimeHintsRegistrar dichiara le risorse lette a runtime
- Un test verifica gli hint senza compilare in nativo
- native:compile crea un eseguibile che parte in un istante
- Costi: tempo di build, vincoli, nessun JIT

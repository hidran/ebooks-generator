# Lezione 110b. Deploy su Google Cloud Run (facoltativa)

## Punti chiave

### Perché Cloud Run

- Container serverless: niente macchine e niente cluster da gestire
- Scala da zero istanze quando non arrivano richieste
- Livello gratuito mensile, con limiti da controllare sul listino
- Kubernetes per un solo servizio? No: KISS

> Percorso: Mac, poi Artifact Registry, poi Cloud Run, poi URL pubblico.

### Prima di registrare (fuori camera)

- Account Google Cloud e fatturazione attiva
- gcloud installato, gcloud auth login, progetto dedicato al corso
- API attivate e gcloud auth configure-docker per il registry
- PROJECT_ID=shop-demo-123456: valore fittizio, usate il vostro
- Regione europe-west8, Milano

### Costi e pulizia

- Prezzi e soglie gratuite cambiano: fa fede il listino ufficiale
- --min-instances 0: nessun container acceso senza richieste
- --max-instances 2: un tetto alle istanze e alla spesa
- Il registry fa pagare lo spazio oltre la quota gratuita
- Avviso di budget prima, servizio e repository cancellati dopo

### Segreti e cosa non serve

- Mai password in --set-env-vars: sono visibili nella configurazione
- Secret Manager e --set-secrets per i segreti
- Non servono: Kubernetes, Cloud Build, database, dominio proprio
- Un'immagine, un comando, un indirizzo pubblico

~~~java
package com.shop;

import static org.springframework.test.web.servlet.request.MockMvcRequestBuilders.get;
import static org.springframework.test.web.servlet.request.MockMvcRequestBuilders.post;
import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.header;
import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.jsonPath;
import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.status;

import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.context.SpringBootTest;
import org.springframework.boot.webmvc.test.autoconfigure.AutoConfigureMockMvc;
import org.springframework.http.MediaType;
import org.springframework.test.web.servlet.MockMvc;

@SpringBootTest
@AutoConfigureMockMvc
class ProductApiTests {
    @Autowired
    MockMvc mvc;

    @Test
    void listsTheDemoProducts() throws Exception {
        mvc.perform(get("/api/products"))
                .andExpect(status().isOk())
                .andExpect(jsonPath("$[0].name").value("Keyboard"))
                .andExpect(jsonPath("$[1].name").value("Mouse"));
    }

    @Test
    void createsAProduct() throws Exception {
        mvc.perform(post("/api/products").contentType(MediaType.APPLICATION_JSON)
                        .content("{\"name\":\"Monitor\",\"priceInCents\":18900}"))
                .andExpect(status().isCreated())
                .andExpect(header().exists("Location"))
                .andExpect(jsonPath("$.name").value("Monitor"));
    }

    @Test
    void rejectsAnInvalidProduct() throws Exception {
        mvc.perform(post("/api/products").contentType(MediaType.APPLICATION_JSON)
                        .content("{\"name\":\" \",\"priceInCents\":0}"))
                .andExpect(status().isBadRequest())
                .andExpect(jsonPath("$.type").value("https://api.shop.example/problems/validation-error"));
    }

    @Test
    void readinessProbeIsUp() throws Exception {
        mvc.perform(get("/actuator/health/readiness"))
                .andExpect(status().isOk())
                .andExpect(jsonPath("$.status").value("UP"));
    }

    @Test
    void reportsAMissingProduct() throws Exception {
        mvc.perform(get("/api/products/999"))
                .andExpect(status().isNotFound())
                .andExpect(jsonPath("$.type").value("https://api.shop.example/problems/product-not-found"));
    }
}
~~~

## Comandi della lezione

I comandi che scriviamo nel terminale durante il video, nell'ordine.

~~~bash
./mvnw -B test
gcloud artifacts repositories create shop --repository-format docker --location europe-west8
IMAGE=europe-west8-docker.pkg.dev/$PROJECT_ID/shop/shop:1
docker build --platform linux/amd64 -t "$IMAGE" .
docker push "$IMAGE"
gcloud run deploy shop --image "$IMAGE" --region europe-west8 \
  --port 8080 --memory 512Mi --min-instances 0 --max-instances 2 \
  --set-env-vars MANAGEMENT_ENDPOINT_HEALTH_SHOW_DETAILS=never \
  --startup-probe httpGet.path=/actuator/health/readiness,periodSeconds=2,failureThreshold=30 \
  --allow-unauthenticated
gcloud run services delete shop --region europe-west8 --quiet
gcloud artifacts repositories delete shop --location europe-west8 --quiet
~~~

## Riepilogo

- Profilo cloud: porta da PORT, ascolto su 0.0.0.0, due test
- Build per linux/amd64 senza emulazione, push su Artifact Registry
- gcloud run deploy con limiti di istanze e sonda di readiness
- Una chiamata pubblica, poi servizio e repository cancellati

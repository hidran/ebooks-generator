# Parte 16. Java in azienda

Le quindici parti del corso ci hanno portato da zero a un sistema Spring Boot completo, con il suo frontend Angular. Questa parte non ha video: l'abbiamo scritta per il libro, pensando al primo giorno di lavoro in una banca, in un'assicurazione o in una grande società di consulenza informatica.

Lì il codice non nasce oggi. Ci sono importi da calcolare al centesimo, file che arrivano ogni notte da altri sistemi, database che esistono da vent'anni, progetti scritti con strumenti che nel corso non abbiamo usato. Nessuno di questi argomenti è difficile, se qualcuno te lo spiega una volta con calma. È quello che facciamo nei sei approfondimenti che seguono.

Ogni capitolo parte da quello che già sai, usa lo stesso progetto Shop e finisce con gli errori tipici di chi comincia e con il posto in cui incontrerai l'argomento al lavoro. Il codice compila e i test passano con le stesse versioni del corso: Java 25 e Spring Boot 4.1.

- Approfondimento 2. Test unitari con Mockito
- Approfondimento 3. File che arrivano da altri sistemi
- Approfondimento 4. Leggere il codice che c'è già
- Approfondimento 5. I database delle aziende
- Approfondimento 6. Lavorare a lotti con Spring Batch

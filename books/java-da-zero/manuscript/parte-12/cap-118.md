# Lezione 93b. Docker su Windows e Linux

## Punti chiave

### Un motore, tre sistemi

- macOS: Docker Desktop, come nella lezione 93
- Windows: Docker Desktop con WSL 2
- Linux: Docker Engine, direttamente sul sistema
- I comandi docker della sezione restano identici

> Percorso: Client docker, poi Motore Docker, poi Container.

### Windows: WSL 2

- PowerShell come amministratore: wsl --install
- WSL già presente: wsl --update; poi riavvio
- Verifica: wsl --version, almeno la 2.1.5
- Virtualizzazione attiva nel BIOS o UEFI

### Windows: Docker Desktop

- docs.docker.com: Docker Desktop Installer.exe
- Windows 11, o Windows 10 22H2, a 64 bit, 8 GB di RAM
- Modalità per utente (consigliata): niente diritti di amministratore
- Configurazione: Use WSL 2 instead of Hyper-V
- Avvio dal menu Start, poi Accept delle condizioni d'uso

### La licenza di Docker Desktop

- Gratuito: uso personale, studio, open source non commerciale
- Gratuito per imprese sotto 250 dipendenti e 10 milioni di dollari annui
- Aziende più grandi ed enti pubblici: abbonamento a pagamento
- Le condizioni cambiano: verificatele su docker.com

### Verifica su Windows

- docker version: sezioni Client e Server
- docker run hello-world: Hello from Docker!
- docker compose version: Compose è incluso
- Ubuntu in WSL: Settings, Resources, WSL Integration

### Linux: Docker Engine

- Repository ufficiale di Docker, non il pacchetto della distribuzione
- Chiave e repository: comandi su docs.docker.com/engine/install
- sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
- sudo docker run hello-world

### Linux: docker senza sudo

- sudo usermod -aG docker $USER
- Uscire e rientrare nella sessione
- docker run hello-world, ora senza sudo
- Il gruppo docker equivale a privilegi di root

### Stessi comandi ovunque

- version, run, ps, logs, stop, rm, volume, build, compose
- Stesse immagini con versione precisa, porte su 127.0.0.1
- PowerShell: ogni comando su una riga sola
- Maven: .\mvnw.cmd al posto di ./mvnw

`README.md`

~~~markdown
# Lesson 93b: Docker on Windows and Linux

The Docker commands of section 12 are the same on macOS, Windows and Linux. Only the engine installation changes.

## Windows: WSL 2 and Docker Desktop

In PowerShell **as administrator**, then restart:

```powershell
wsl --install      # first time
wsl --update       # WSL already installed
wsl --version      # Docker Desktop needs WSL 2.1.5 or later
```

Hardware virtualization must be enabled in the BIOS/UEFI.

1. Download `Docker Desktop Installer.exe` from the Docker documentation (Install Docker Desktop on Windows).
2. Requirements listed by Docker: Windows 11 23H2 (build 22631) or later, or Windows 10 22H2 (build 19045), 64 bit,
   8 GB of RAM.
3. Installation mode: per user (recommended, no administrator rights) or all users.
4. Configuration page: keep **Use WSL 2 instead of Hyper-V**.
5. Start Docker Desktop from the Start menu and accept the Docker Subscription Service Agreement.

License (check the current terms on docker.com): Docker Desktop is free for personal use, education, non-commercial
open source projects and small businesses (fewer than 250 employees AND less than 10 million US dollars in annual
revenue). Larger companies and government entities need a paid subscription.

Checks, in a normal PowerShell window:

```powershell
docker version
docker run hello-world
docker compose version
```

From an Ubuntu distribution in WSL: Docker Desktop, Settings > Resources > WSL Integration.

## Linux: Docker Engine (Ubuntu)

Set up Docker's `apt` repository with the commands of the official page (Install Docker Engine on Ubuntu; other
distributions have their own page), then:

```bash
sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
sudo docker run hello-world
```

Run `docker` without `sudo` (the `docker` group grants root-level privileges on the machine):

```bash
sudo usermod -aG docker $USER
# log out and log back in, then:
docker run hello-world
```

## The section's commands on Windows

- Write each command on a single line in PowerShell (the line continuation character there is the backtick, not `\`).
- Maven wrapper: `.\mvnw.cmd` in PowerShell instead of `./mvnw`.
~~~

- Linux: Docker Engine dal repository ufficiale, utente nel gruppo docker
- Verifica: docker version e docker run hello-world

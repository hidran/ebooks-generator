# Lezione 93. Container e Docker, concetti e motore su macOS

## Punti chiave

### Il problema

- Sulla mia macchina funziona: e sulle altre?
- Versione di Java, database e configurazione cambiano
- Un container porta con sé ciò che serve per girare
- Docker l'abbiamo già usato per PostgreSQL: ora lo capiamo

### I concetti

- Immagine: modello in sola lettura, fatto di layer
- Container: un'immagine in esecuzione, con un processo
- Registry: archivio da cui scarichiamo le immagini
- Tag preciso, mai latest: eclipse-temurin:25.0.4.1_1-jre-noble

> Percorso: Registry, poi Immagine, poi Container.

### Docker su macOS

- I container usano il kernel Linux
- Su macOS serve una piccola macchina virtuale Linux
- Docker Desktop la avvia e tiene acceso il motore
- Licenza: gratuito per uso personale, studio e piccole imprese, abbonamento per le aziende più grandi
- Il comando docker è il client, il motore è il server

### Porte e volumi

- -p 127.0.0.1:18123:5432: porta pubblicata solo in locale
- -v shop-data:/var/lib/postgresql: volume con nome
- Il container si cancella, il volume resta
- docker ps, logs, stop, rm, volume ls

## Codice della lezione

`README.md`

~~~markdown
# Lesson 93: containers and Docker

Commands shown in the lesson, in order. The engine on macOS is Docker Desktop: start it before running the commands (Colima is a free alternative).

```
docker version
docker image ls
docker run --rm eclipse-temurin:25.0.4.1_1-jre-noble java -version
docker volume create shop-data
docker run -d --name shop-db -e POSTGRES_PASSWORD=demo-only -p 127.0.0.1:18123:5432 -v shop-data:/var/lib/postgresql postgres:18.6-alpine3.24
docker ps
docker logs shop-db
docker stop shop-db
docker rm shop-db
docker volume ls
docker run -d --name shop-db -e POSTGRES_PASSWORD=demo-only -p 127.0.0.1:18123:5432 -v shop-data:/var/lib/postgresql postgres:18.6-alpine3.24
docker logs shop-db
docker rm -f shop-db
docker volume rm shop-data
```

`demo-only` is a demo password for a local, throwaway database: never use it for anything real.
The port is published on 127.0.0.1 only, so the database is not reachable from the network.
~~~
